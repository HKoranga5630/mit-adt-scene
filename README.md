# Mit Adt Scene

Create a responsive college website called "College Club Management & Event Hub".

This project is for MIT ADT University.

The purpose of the website is to provide one centralized platform where students can discover college clubs and events, register for events, and join clubs. Club representatives should be able to manage their club and events, and administrators should be able to manage users, clubs and events.

Create the initial frontend with these pages:

1. Home

2. Clubs

3. Events

4. Login

5. Sign Up

Home page should include:

- MIT ADT University branding

- Website name: College Club Management & Event Hub

- A professional hero section

- Short introduction about the platform

- Upcoming Events section

- Popular Clubs section

- Call-to-action buttons

- Footer

Clubs page should display college clubs with:

- Club logo/image

- Club name

- Category

- Short description

- View Club button

Events page should display event cards with:

- Event poster

- Event name

- Date

- Time

- Venue

- Organizing club

- View Details button

Use a clean, modern and professional college-project design.

Make it responsive for mobile, tablet and desktop.

For now, create only the frontend UI and navigation.

Do not add Firebase yet.

Do not create fake authentication or database functionality yet.

Keep the code organized so Firebase can be integrated later.
